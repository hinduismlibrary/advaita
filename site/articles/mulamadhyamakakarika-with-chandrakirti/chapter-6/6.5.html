MMK 6.5

ekatve = in identity; sahabhāvaḥ = coexistence; cet = if; syāt = were; sahāyam = companion; vinā = without; api = even; saḥ = that; pṛthaktve = in difference; sahabhāvaḥ = coexistence; cet = if; syāt = were; sahāyam = companion; vinā = without; api = even; saḥ = that

Original Sanskrit (GRETIL)

ekatve sahabhāvaścetsyātsahāyaṃ vināpi saḥ | pṛthaktve sahabhāvaścetsyātsahāyaṃ vināpi saḥ || 5 ||

Candrakīrti’s Commentary

If co-existence follows from identity, then every thing that is identical with itself would automatically be together with itself; the relation would no longer distinguish anything. If co-existence follows from difference, then every different thing would be together with every other different thing, even without any connection—like a cow existing together with a horse. Neither conclusion makes sense.

The opponent’s account would thus make co-existence either automatic for one thing or universal among unrelated things. It cannot explain the particular relation between desire and the desirous person.
