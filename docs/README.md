# Website source

This directory contains the complete website. Its original public paths remain unchanged, even though this directory is nested under `docs/` in GitHub. GitHub Pages must publish from **main /docs** after the planned cutover.

## Browse the site by subject

- **[Purāṇas](puranas/README.md)** — individual texts organized by parvan, book, and canto.
- **[Articles and documents](articles/README.md)** — scriptural studies, research, and individual reader HTML files.
- **[Advaita books](books/README.md)** — Śaṅkara and related Advaita works.
- **[Collection landing pages](pages/README.md)** — entry points for the Purāṇas, philosophy and introductions.
- **[Site assets](assets/README.md)** — CSS, scripts, source data, and images.
- **[Contact](contact/)** — contact page.

The top-level `index.html`, `404.html`, `favicon.svg`, and `sitemap.xml` are intentionally kept here as standard Pages files. Do not rename reader HTML folders solely for source organization: they are also established public URLs.
