# Website assets

- **[css/](css/)** — shared site and reader styles.
- **[js/](js/)** — interactive readers, navigation, search and controls.
- **[data/](data/)** — Sanskrit and commentary source datasets, per-text manifests, and word-for-word material.
- **[images/](images/)** — images, covers and source-document illustrations.

Assets remain at their existing public `/advaita/assets/` paths when Pages publishes from `/docs`. Scripts and data are kept separate from the HTML readers to preserve dynamic loading.
