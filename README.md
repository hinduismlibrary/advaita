# Advaita

Sanskrit texts, literal English translations, commentaries, and research.

**[Read the website](https://krishnavyasmuni.github.io/advaita/)** · **[Browse the Purāṇas](docs/puranas/README.md)**

## Repository map

- **[docs/](docs/)** — website source, with existing public paths kept intact.
  - **[puranas/](docs/puranas/)** — separate folders for each Purāṇa and its books, cantos, and parvans.
  - **[pages/](docs/pages/)** — collection landing pages and reading introductions.
  - **[articles/](docs/articles/)** — original chapter readers and documents, preserving old URLs.
  - **[books/](docs/books/)** — Advaita texts and treatises.
  - **[assets/](docs/assets/)** — styles, scripts, source data, and images.
  - **[contact/](docs/contact/)** — contact page.
- **[.github/](.github/)** — workflows, maintenance, audits, and repository templates.
- **[.gitignore](.gitignore)** — local-only files to ignore.
- **[CONTRIBUTING.md](CONTRIBUTING.md)** — editing and publishing guide.

**Deployment:** this tree is ready to be published from `main /docs`. It must not replace the live `main` branch while Pages is configured to publish from `main /`.
