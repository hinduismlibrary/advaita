MMK 8.2

One who exists has no activity; [something] would also exist as an act without an actor. One who exists has no activity; [something] would also exist as an actor without an act.

Original Sanskrit (GRETIL)

sadbhūtasya kriyā nāsti karma ca syādakartṛkam | sadbhūtasya kriyā nāsti kartā ca syādakarmakaḥ || 2 ||

Candrakīrti’s Commentary

An actor is called an actor because of an activity. If the actor is already established as real through an activity, there is no second activity by which that actor could perform the action in question. Without that further activity, the action would occur with no actor. The same applies to an action already established as real: it is already activity, so no second action remains to be done. If it is not done by an actor, it would be an action without an agent. Neither a real actor doing a real action nor a real action done by an actor is established.
